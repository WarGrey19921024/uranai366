## 6. 計算ロジック（共通JS）

| 占術 | 試作 | 本番 |
|---|---|---|
| 本命星・年の位置 | 立春2/4固定 | 立春は年ごとの日付表で |
| 四柱推命 | 年柱・月柱（節入り概算）・日柱 | 節入りは年ごとの節気時刻表で |
| 宿曜 | 月の位置からの簡易計算 | **旧暦変換表＋宿曜経の表で正式に**（1930〜2020年） |
| マヤ暦 | ドリームスペル方式（基準 2013-07-26=KIN164） | そのまま＋紋章・音の解説 |
| ライフパス | 各けたの合計（11・22・33は残す） | そのまま |
| 動物×色 | 枠のみ | **`/animal-color/` の既存計算を流用** |
| バイオリズム | 23・28・33日。★◎〇△▽は ≥0.8／≥0.4／≥-0.2／≥-0.6／それ未満 | そのまま |

| 誕生日カード画像 | canvasでPNG | そのまま |
