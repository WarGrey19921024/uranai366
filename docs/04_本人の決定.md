- **数字だけのスラッグは WordPress では使えない**。固定ページなどの階層型ページでは、`0101` のような数字だけのスラッグは自動で `0101-2` に変えられる（`wp-includes/post.php` の `wp_unique_post_slug()`：`preg_match( "@^($wp_rewrite->pagination_base)?\d+$@", $slug )`）。しかも固定ページの書き換えルール `(.?.+?)(?:/([0-9]+))?/?$` では `/birthday/0101/` は「`birthday` ページの 101 ページ目」と読まれ、子ページに届かない
- **`/birthday/` はすでに画像の添付ファイルページ（ID 4330）が使っている**ので、親ページ `birthday` も作れない
