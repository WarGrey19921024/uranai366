## 3. 調査するときのルール

  過去に「投稿約506件」と記録していたが、実際は762件だった（ページ取得ツールの出力が途中で切れていたのが原因）。

## 5. やってはいけないこと

* **2026-09-05追記: Search Console（Site Kit）の直近1〜2日の数字は確定値ではない。** 同じAPI・同じ日付・同じ期間で取り直すと、**あとから増える**（2026-09-04 の表示回数が 0 → 1 に変わった実例）。**「最新日が0だから流入が止まった」と読まないこと。** 推移を判断するときは最新2日を除いて見るか、2日待ってから取り直す。
