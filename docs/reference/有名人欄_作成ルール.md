## 1. 人数

| 区分 | 人数 |
|---|---|
| 日本の有名人 | **8名** |
| 海外の有名人 | **5名** |

- **2月29日は候補が少ないので減らしてよい。** 他の日でも、基準を満たす人が足りなければ**無理に埋めない**（水増しより少ないほうがよい）

## 2. 顔ぶれ

- **歴史上の人物を入れてよい**（ビスマルク、マズローなど）
- 分野が偏らないようにする（俳優・音楽・スポーツ・文化人・政治・学術などを散らす）
- 日本の一般読者が名前を見て分かる人を優先する

## 2-2. 🔴 人選の追加基準（2026-09-25 翔太さん決定）

| 対象 | 扱い |
|---|---|
| **犯罪歴のある人** | 🔴 **何年前でも入れない**（逮捕・書類送検・起訴・略式・有罪。薬物・飲酒運転・暴行・脱税・わいせつ・賭博など。歴史上の人物も同じ） |
| **直近5年に不祥事があった人** | 🔴 **入れない**（不倫・ハラスメント・差別発言などで処分・活動休止・契約解除になったもの、反社との関係報道など） |
| 5年以上前の、犯罪ではない不祥事 | 入れてよい |
| **政治家**（議員・首長・閣僚・国家元首を務めた人） | 🔴 **よほど大きなことを成し遂げた人以外は入れない** |

- 政治家として残しているのは次の人だけ: ジョージ・ワシントン、セオドア・ルーズベルト、ウッドロウ・ウィルソン、ネルソン・マンデラ、ジミー・カーター、シャルル・ド・ゴール、リー・クアンユー、孫文、コラソン・アキノ、ウィリアム・ウィルバーフォース、市川房枝、吉田茂、マーガレット・サッチャー、アンゲラ・メルケル、李登輝
- 本業が別にある人（堀内恒夫・谷亮子・荻原健司・ロマーリオ・橋本聖子・アントニオ猪木・マニー・パッキャオなど）は、本業の職業で残す
- 君主・皇族（象徴的地位）はこれまでどおり入れてよい
- 外交官・政治学者・思想家は「政治家」に含めない
- 疑惑だけで処分も立件もないもの（本人が否定・不起訴で逮捕なし等）は外さず、要確認として記録する

## 2-3. 暦の補足（2026-09-25）

- **1872年以前に生まれた日本人**は入れない（旧暦換算のため）
- 海外は、**1918年以前のロシア帝国（ポーランド・バルト・ウクライナ等を含む）**、**1752年以前の英国・英植民地**、**1582年以前の欧州**、**1700〜1753年のスウェーデン**の生まれは入れない（ユリウス暦の日付のため）
- 洗礼日しか分からない人、生年月日に複数説がある人も入れない

## 3. 🔴 故人の扱い（最重要・見落とさないこと）

**亡くなり方で線を引く。**

| | 扱い |
|---|---|
| 病死・老衰・大往生 | ✅ **入れる** |
| **自殺** | 🔴 **入れない** |
| **事故死**（交通事故・墜落・転落など） | 🔴 **入れない** |
| **事件・殺害・暗殺** | 🔴 **入れない** |
| **災害死・戦死・処刑** | 🔴 **入れない** |

- 存命の方はそのまま入れてよい
- **故人は全員、死因を確認してから採否を決める。** 確認できなければ入れない
- ⚠ **死因はサイトには一切書かない。** これは**選ぶときの基準としてだけ**使う（R11＝名前と職業のみ、は変わらない）
- ⚠ 若くして病気で亡くなった方は「入れる」側に分類している。ここは判断が分かれるところなので、**気になったら翔太さんに確認する**

## 4. 職業の書き方

- **1〜3語で短く**（例: 俳優／歌手／映画監督／小説家）
- 🔴 **「元」をつけない。** 「元プロ野球選手」ではなく **「プロ野球選手」**
  - 理由: 現役か引退かは時間で変わるので、つけると古くなる
- 肩書きは ja.wikipedia の記述に沿う。勝手に格上げ・格下げしない


## 4-2. 🔴 「戸籍上の日付」は向きを見て判断する

本人記事に戸籍と実際のずれが書かれていることがある。**どちらがその日なのかで扱いが逆になる。**

| 人物 | 注記 | 扱い |
|---|---|---|
| 王貞治 | 実際5/10・**戸籍が5/20** | **5/10に採用**（5/20からは除外） |
| 伊福部昭 | 実際5/31・**戸籍が3/5** | **5/31に採用** |
| 美川憲一 | **戸籍が5/15**・実際5/4 | 5/15から**除外** |
| カンニング竹山・浪川大輔・林真理子 | **戸籍が4/1〜2**・実際は3月末 | **除外** |

→ **「実際の日付がその日」なら採用、「戸籍の日付がその日」なら除外。**

## 4-3. 日付記事の取得

⚠ **1回の取得だと要約で返り、候補を大きく取りこぼすことがある。** 5/6でフロイトが出てこなかった。**候補が異様に少ないと感じたら、年代を区切って取り直す。**

⚠ 本人記事の生年月日が**インフォボックスにしかなく本文から取れない**人物が一定数いる（ヘンリー・カヴィル・みやぞん・荻原博子など）。**英語版で拾えることが多い。**

## 5. 🔴 検証手順（省略しない）

1. `ja.wikipedia.org/wiki/<M月D日>` の「誕生日」セクションから候補を選ぶ
2. **選んだ全員について、本人の記事を個別に開く**。日付記事のリスト自体にも誤りが混入しうる
3. 本人の記事で次を確認する
   - ① 誕生日がその日付か
   - ② 故人なら**死因**（上の3の基準）
   - ③ **暦のずれ・戸籍上の日付**の注記がないか
4. ①②③のどれかで引っかかったら**外して別の人に差し替える**

### 外す例（4月1日で実際に外した人）

| 人物 | 理由 |
|---|---|
| 林 真理子 | **戸籍上は4/1だが実際は3月末日** |
| セルゲイ・ラフマニノフ | ユリウス暦／グレゴリオ暦で日付が変わる |
| ウィリアム・ハーヴェイ | 同上 |
| 加藤 友三郎 | 旧暦由来で信頼性が担保できない |
| 竹内 結子 | **3の基準に該当** |

⚠ **機械的な抽出だけでは足りない。** 小さいモデルに日付記事から抽出させたら、アメリカ人を「日本の有名人」に入れる国籍の取り違えが出た。**選別と検証は判断を伴う工程として扱うこと。**
