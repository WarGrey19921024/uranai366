# 動物×色占い（/animal-color/）の計算方法

2026-10-10、現行ページ https://www.uranai.epoch-compass.com/animal-color/ のJavaScript（`calculateAnimal` 関数）から書き写したもの。**このサイト独自の占い**（一般の「動物占い」とは別物）。

## 計算式
```js
function calculateAnimal(year, month, day) {   // month は 1〜12、day は 1〜31（そのままの数）
  const baseNumber = (year + month * 12 + day) % 60;
  const animalIndex = baseNumber % 12;
  const colorIndex  = Math.floor(baseNumber / 12) % 5;
  // animals[animalIndex] と colors[colorIndex] の組み合わせ → 60タイプ
}
```

## 表示
- 結果は「動物＋色」（例：ライオン・ゴールド）。詳しい性格は `/animal-color/` へリンクする
- 生まれ年パネルでは、この式をそのまま使う（年が必要）

## 検算の例
- 1990年1月1日：(1990 + 12 + 1) % 60 = 2003 % 60 = 23 → 動物 23 % 12 = 11（たぬき）、色 floor(23/12) % 5 = 1（ゴールド）→ **たぬき・ゴールド**
