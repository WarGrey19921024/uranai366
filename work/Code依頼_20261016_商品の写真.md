# （不要になりました）商品の写真のデータ集め

2026-10-16：楽天ウェブサービスの既存アプリ（許可するWebサイトで登録する方式）に、人生予報・夢解き図鑑・はじめての革製品のドメインを追加した。
これで人生予報のページの上からブラウザで楽天APIを呼べるので、ローカルのCodeでの作業は不要になった。
データ集めは、人生予報のページに出した小さな画面（本人がキーを貼る）で行い、結果を goods_rakuten.json としてダウンロード → work/data/ に取り込む。
取り直すときも同じ方法（work/data/goods_queries.json の語を集める）。`fetch_goods.py` はローカルで動かす場合の予備。
