# Code依頼（2026-10-16）：商品ボックスに商品の写真を出す

本人の要望：「探す」ボタンだけでは、どんな物かわからず買うイメージがわかない → 写真つきの商品カード（Rinker・ポチップ型）にする。
仕組みはクラウドで作成済み（`work/scripts/fetch_goods.py`・`goods_media.py`。ビルドは写真データがあれば自動で写真と商品ページへのリンクに切り替わる）。
楽天の新APIは「許可したIPアドレス」からしか呼べないため、**本人のパソコンで**データ集めだけ行う。

## 本人が先にやること
1. 楽天ウェブサービス（https://webservice.rakuten.co.jp/）にログイン → 「+ New App」でアプリを作る
   - アプリ名：人生予報 商品カード（何でもよい）／アプリケーションURL：https://www.uranai.epoch-compass.com/
   - Allow IP address：自宅のIPアドレス（固定でなければ、Code に「今のIPアドレスを調べて」と頼む）
   - 出てきた **アプリID（UUID）** と **アクセスキー（pk_…）** を控える（チャットやファイルには貼らない）
2. （任意）Yahoo!デベロッパーネットワークで Client ID を取る → Yahoo!ボタンも商品ページ＋写真にできる

## Code にやってもらうこと（この md をそのまま渡す）
1. `git pull`（main）
2. ターミナルで本人にキーを入れてもらう（Code はキーを表示・保存しない）
   ```
   set RAKUTEN_APP_ID=（本人が入力）
   set RAKUTEN_ACCESS_KEY=（本人が入力）
   set YAHOO_APP_ID=（任意）
   ```
3. 試しに20語：`.venv\Scripts\python -X utf8 work\scripts\fetch_goods.py --limit 20`
   - `work\data\goods_rakuten.json` に 写真URL（thumbnail.image.rakuten.co.jp）・商品ページURL（item.rakuten.co.jp）が入ればOK
   - 403 が出たら：アプリ設定の許可IPアドレスを確認
4. 全部：`.venv\Scripts\python -X utf8 work\scripts\fetch_goods.py`（約4,100語・約2時間。止まっても続きから）
5. `work\data\goods_rakuten.json`（と `goods_yahoo.json`）だけをコミットして push（キーは入っていない。入っていないことを確認）
6. 終わったら本人に「完了」と伝える → クラウドの Claude がページを作り直して本番に反映する

## 注意
- キーをファイル・コミット・チャットに書かない（このリポジトリは公開）
- 写真と商品は2か月に1回ほど取り直す（売り切れ対策）：`fetch_goods.py --refresh 60`
