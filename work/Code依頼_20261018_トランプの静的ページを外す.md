- `.htaccess` も変更前のものを保存

## 2. ほかのページが /trump/ の中のファイルを使っていないか確かめる
- 画像・CSS・JS などを、ほかの静的ページが読み込んでいないか検索する。使っているものがあれば止めて本人に報告

## 3. フォルダの名前を変えて退避
- `/trump/` を `/_trump_stopped_20261018/` に名前変更（中身は変えない）

## 4. .htaccess（`# BEGIN WordPress` より前。ほかの行は変えない）
| 古いURL | 転送先 |
|---|---|
| /trump/one/・/trump/two/・/trump/three/（最後の / なし・index.html つきも） | /trump/ |
| /_trump_stopped_20261018/ 以下すべて | /trump/ |
