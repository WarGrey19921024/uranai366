# Code依頼（ローカル・FTP）2026-10-18 /rune/ の静的ページを外して、WordPress の新しいページを表示させる

ルーン占いを WordPress の固定ページ（ID 11178、スラッグ rune）として作り直して公開した。ただ、サーバーに静的ページのフォルダ `/rune/` があるため、今は古い静的ページが表示され、新しいページは表に出ていない。静的のフォルダを外して、同じURL（/rune/）で新しいページが出るようにする。WordPress の中身は触らない。

## 1. バックアップ
- サーバーの `/rune/` フォルダの中身をすべて `12_占いサイト/バックアップ/20261018_ルーンの静的ページ/` にダウンロードする（ファイル数とサイズを記録）
- `.htaccess` もバックアップに入れておく（変えないが念のため）

## 2. ほかのページが /rune/ の中のファイルを使っていないか確かめる
- `/rune/` の中の画像・CSS・JS などを、ほかの静的ページ（/dice/・/trump/・/mbti-diag/・/mbti-compatibility/ など）が読み込んでいないか検索する
- 使っているものがあれば、外さずに止めて本人に報告する（その場合はファイル名と使っているページを書く）

## 3. 静的のフォルダを外す
- 使われていないことを確かめたら、サーバー上の `/rune/` フォルダを削除する（中身はバックアップ済みなので、戻すときはそこからアップロードし直す）
- `.htaccess` は変えない（/rune/ への転送は不要。同じURLで WordPress のページが出る）

## 4. 終わったら確かめる
- https://www.uranai.epoch-compass.com/rune/ を開くと、新しいページ（題名「ルーン占い【無料】25のルーンの意味一覧（正位置・逆位置）…」、ボタン「ルーンを引く」）が出ること
- https://www.uranai.epoch-compass.com/rune/index.html は404か、/rune/ に移ること（どちらでもよい。結果だけ報告）
- トップページ・/dice/・/trump/・/suhijutsu/ が200のまま表示されること
- これまでの転送（/number-fortune/ → /suhijutsu/、/number-fortune/tarot/ → /tarot/、/number-fortune/trump/ → /trump/、/blood-week/ → /blood/）がそのまま動くこと
- FTPの接続情報のファイルを消し、本人に短く報告する
