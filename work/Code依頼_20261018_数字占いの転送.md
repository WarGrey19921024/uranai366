# Code依頼（ローカル・FTP）2026-10-18 /number-fortune/ を /suhijutsu/ へ301

静的ページの「数字占い」（/number-fortune/）は、新しい WordPress の固定ページ「数秘術」（/suhijutsu/、ID 11173）にまとめた（クラウドで公開済み。好きな数字で読むコーナーも入れてある）。古いURLを新しいページへ転送する。WordPress の中身は触らない。

作業の前に `.htaccess` と、書き換える静的ページのバックアップを `12_占いサイト/バックアップ/20261018_数字占いの転送/` に取ること。

## 1. .htaccess に301を足す
これまでの転送（/number-fortune/tarot/・/number-fortune/trump/・/blood-week/）と同じ書き方で、`# BEGIN WordPress` より**前**に入れる。

| 古いURL | 転送先 |
|---|---|
| /number-fortune/ | /suhijutsu/ |
| /number-fortune/index.html | /suhijutsu/ |
| /number-fortune（最後の / なし） | /suhijutsu/ |

- **/number-fortune/ の下にあるほかのページ（tarot・trump の転送や、まだ残っているファイル）は巻き込まないこと。** 転送するのは上の3つだけ（`RedirectMatch 301 ^/number-fortune/?(index\.html)?$ /suhijutsu/` のように、ちょうどその URL だけに当たる書き方にする）
- ほかの行は変えない
- 古いファイルは消さずに残してよい

## 2. 静的ページの中の古いリンクを直す
静的ページ（/dice/・/trump/・/rune/・/mbti-diag/・/mbti-compatibility/ など、FTP上の .html）の中に、`/number-fortune/`（または `/number-fortune/index.html`）そのものへのリンクがあれば、リンク先を `/suhijutsu/`、文字の「数字占い」を「数秘術」に書き換える（絵文字はほかのメニューにそろえて残してよい）。`/number-fortune/○○/` のような下のページへのリンクは変えない。直したファイルもバックアップに入れておく。
