# ローカルの Claude Code への依頼：1月1日・1月2日の有名人の生年（2026-10-22）

クラウドからは日本語版ウィキペディアの「1月1日」「1月2日」のページが長すぎて途中（1905年・1937年生まれ）までしか読めなかった。ローカルで続きを読んで、生年を足す。

## やること
1. `git pull`（main）
2. 次の2ページの「誕生日」の節を読む（ブラウザか、`?action=raw` の本文）
   - https://ja.wikipedia.org/wiki/1月1日
   - https://ja.wikipedia.org/wiki/1月2日
3. `work/data/famous_years/0101.json`・`0102.json` の `missing` の人について、誕生日の節の行（例「1956年 - 役所広司、俳優」）から生年を取り、`years` に入れ、`quotes` にその行を入れ、`missing` から外す
   - 決まり：その行に名前と年の両方があるときだけ。無い人は `missing` に残す。推測しない
   - 名前は `source/famous/01月.md` の表記のまま（ページの表記が少し違うだけの同じ人は、年を入れて `quotes` に「ページの表記は〜」と書く）
   - 形式は今の JSON のまま（UTF-8・indent=1）
4. `.venv\Scripts\python -X utf8 work\scripts\build_html.py 0101 0102`
5. コミットして push（main）。サイトへの入れ直しはクラウドの Claude が行う
