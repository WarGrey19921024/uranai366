# パソコンのClaudeへの依頼：2026年版の誕生日ページを2027年版へ転送（2027年1月1日に実施）

**実施日：2027年1月1日（それより前には入れない）。** 2026年版のページは2026年のあいだ読まれるため。

## やること
サーバーの `.htaccess`（サイトのいちばん上の階層）に、次の2行を足す。

1. 作業前に `.htaccess` を `.htaccess.bak.20270101` として控える
2. 2025年版の転送の行（`RedirectMatch 301 ^/2025-(\d{2})(\d{2})/?$ /366uranai/$1-$2/` と `^/366uranai/2025y/?$`）を探し、**そのすぐ下**に次の2行を貼る（「# BEGIN WordPress」より上であること）

```
# 2027-01-01 2026年版 → 2027年版
RedirectMatch 301 ^/2026-(\d{2})(\d{2})(/.*)?$ /366uranai/$1-$2/
RedirectMatch 301 ^/366uranai/2026y/?$ /366uranai/
```

- 1行目は `/2026-0101/` も `/2026-0101/feed/` なども、まとめて `/366uranai/01-01/` へ送る（2025年版の行は末尾の `/` だけなので、feed などは送られない。2026年版は広めにした）
- 2026年は2月29日がないが、`/2026-0229/` という投稿は存在する → `/366uranai/02-29/` へ送られる（2027年版の 02-29 ページはある）

3. 保存後、次の3つをブラウザかcurlで確認（どれも 301 で転送先が正しいこと）
   - `/2026-0101/` → `/366uranai/01-01/`
   - `/2026-1231/` → `/366uranai/12-31/`
   - `/366uranai/2026y/` → `/366uranai/`
4. 表示がおかしい（サイト全体が 500 など）ときは、すぐ `.htaccess.bak.20270101` に戻す

## 終わったら
結果（足した2行と確認結果）をこちらのチャットに貼ってください。366本すべての転送は、こちらのClaudeがまとめて確認します。
