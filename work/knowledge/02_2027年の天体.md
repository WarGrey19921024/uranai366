# 02 2027年の天体

> この表はすべて `work/scripts/calc_planets_2027.py`（pyswisseph 2.10.03・暦ファイル不要のMoshier方式）で計算し、`work/scripts/render_planets_md.py` で書き出したもの。**手で書いた日付はない。** 再現：`cd work/scripts && python calc_planets_2027.py && python render_planets_md.py`

## ① 定義
- 星座＝太陽の通り道（黄道）を春分点から30度ずつ12に分けたもの（トロピカル方式）。天体の「星座移動」は、その天体の黄経が30度の倍数を通る瞬間。
- 逆行＝地球から見て天体が黄道を逆向きに動いて見える期間。向きが変わる瞬間を「留（りゅう）」と呼ぶ。
- 日食・月食＝太陽・月・地球が一直線に並ぶときの食。「世界のどこかで起きる食」と「日本で見える食」は別。

## ② 計算方法
- 黄経は**視黄経**（その時点の春分点基準・光行差込み）。国立天文台の暦と同じ考え方。
- 星座移動：1日きざみで黄経を調べ、30度の境を越えた区間を二分法で1秒以下まで絞る。逆行で境を戻る通過も拾う（表の「逆行で前の星座に戻る」）。
- 留：黄経の1日あたりの速さの符号が変わる瞬間を二分法で求める。
- 日食・月食：Swiss Ephemeris の `sol_eclipse_when_glob` / `lun_eclipse_when`。日本で見えるかは東京（東経139.74度・北緯35.66度）で判定（日食は東京での食の有無、月食は食の最大時に月が地平線より上か）。
- 時刻は日本時間（JST）で分に四捨五入。精度：Moshier方式は惑星で角度の1秒程度、時刻にして数分以内。

### 2027年の天体の要点（文章を書くときの事実）
- **土星**：1年を通して**牡羊座**（8月10日〜12月24日は逆行）。※デザインモックの「土星が魚座」は誤り。
- **木星**：年初は**獅子座**（1月〜4月13日は逆行）。**7月26日に乙女座へ**移り、年末まで乙女座。
- **火星**：年初は乙女座。1月10日から4月1日まで逆行し、2月21日に獅子座へ戻る。5月14日に乙女座、7月15日天秤座、9月2日蠍座、10月16日射手座、11月26日山羊座。
- **水星の逆行**は3回：2/10〜3/3（魚座→水瓶座）、6/11〜7/5（蟹座→双子座）、10/7〜10/28（蠍座→天秤座）（日本時間）。
- **金星**は逆行なし。ほぼ1か月ごとに星座を移る（表参照）。
- **天王星**は双子座、**海王星**は牡羊座、**冥王星**は水瓶座（1年を通して星座移動なし）。
- **日食**：2/7 1:00（日本時間）金環日食（水瓶座）／8/2 19:07 皆既日食（獅子座・皆既の継続が最長で約6分23秒の「世紀の日食」）。どちらも日本では見えない。
- **月食**：3回とも半影月食（2/21・7/19・8/17）。半影月食は肉眼ではほとんど分からない。日本で最大時に月が出ているのは7/19だけ。

## ⑤ 不確かな点
- 星座移動の時刻は計算方式によって数分ずれることがある。ページには「日付」だけを書き、時刻は書かない。
- 木星の7/26乙女座入りは外部サイトで照合できていない（計算のみ）。土星・木星の日付は暦ファイル（DE431等）でも確認できればなお良いが、この環境ではダウンロード不可。
- 7/19の半影月食は食分がごく小さく、観察はほぼ不可能（NASAの一覧でも「ほとんど見えない」扱い）。文章では「見える」と書かない。
