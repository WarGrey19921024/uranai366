# 05 干支・五行・四柱推命

このサイトでの干支（えと）・五行・四柱推命（しちゅうすいめい）の「定義・計算・解釈」の根拠ファイルです。以後の計算と文章は、このファイルに書いたことだけを根拠にします。

- 計算スクリプト：`work/scripts/calc_kanshi_kyusei.py`（関数 `year_index` / `month_index` / `day_index` / `kanshi`）
- 節入り（月の切り替わり日時）のデータ：`work/data/setsuiri_1900_2100.json`（日本時間・分単位）
- このファイルの計算値（2027年の年柱・月柱、検算の日柱）は、すべて上のスクリプトを実行して得た値です（2026-10-09 実行）。

## ① 定義

- **十干（じっかん）**：甲・乙・丙・丁・戊・己・庚・辛・壬・癸の10個。五行（木・火・土・金・水）を、それぞれ陽（兄＝え）と陰（弟＝と）に分けたものです。
- **十二支（じゅうにし）**：子・丑・寅・卯・辰・巳・午・未・申・酉・戌・亥の12個。方位・時刻・季節（月）を表します。
- **六十干支（ろくじっかんし）**：十干と十二支を順に組み合わせた60通り（甲子から癸亥まで）。60で一回りします（還暦の由来）。
- **五行（ごぎょう）**：世の中のすべてを木・火・土・金・水の5つの性質に分け、その間の「生む・抑える」関係で物事を説明する考え方。
- **四柱推命**：生まれた年・月・日・時刻の4つの「柱」をそれぞれ干支で表し、その組み合わせで性質や運勢を読む占い。このサイトでは時刻が分からないので**年柱・月柱・日柱の3つ**だけを使い、特に**日柱の天干（日干：にっかん）**を「その人の本質」として使います。

## ② 計算方法

番号は六十干支の番号（0＝甲子 … 59＝癸亥）。干支の文字は `KAN[n % 10] + SHI[n % 12]`（スクリプトの `kanshi`）。

### 2-1. 年柱（生まれ年の干支）
- 式：`年柱番号 = (年 − 4) mod 60`（西暦4年＝甲子を基準）
- 「年」は**立春で切り替わる年**。1月1日〜立春の前は前の年の干支です（スクリプトの `eto_year`）。
  - ※一般の「えと（年賀状の干支）」は1月1日で切り替えますが、四柱推命・九星気学では立春で切り替えます。ページ内で混同しないよう、占いの説明では「立春から」と明記します。
- 2027年：(2027 − 4) mod 60 = **43 → 丁未**。立春 2027-02-04 10:46 から。スクリプト実行で 10:45 は丙午、10:47 は丁未。

### 2-2. 月柱（生まれ月の干支）
- 月の十二支：**節入り**で決まります（立春＝寅、啓蟄＝卯、清明＝辰、立夏＝巳、芒種＝午、小暑＝未、立秋＝申、白露＝酉、寒露＝戌、立冬＝亥、大雪＝子、小寒＝丑）。直前の節入りの日時を `setsuiri_1900_2100.json` から探して決めます（スクリプトの `month_branch`）。
- 月の天干：**五虎遁（ごことん）**＝年の天干から寅月の天干を決め、あとは順番に進めます（スクリプトの `month_index`）。

| 年の天干 | 寅月の干支 |
|---|---|
| 甲・己 | 丙寅 |
| 乙・庚 | 戊寅 |
| 丙・辛 | 庚寅 |
| 丁・壬 | 壬寅 |
| 戊・癸 | 甲寅 |

- 境界：節入りの**日時（分単位）**で切り替え。1月（子月の残り・丑月）は、立春前なので**前の年の天干**で五虎遁を使います。

### 2-3. 日柱（生まれた日の干支）
- 式：`日柱番号 = (10 + (その日 − 1900年1月1日の日数)) mod 60`（1900-01-01＝甲戌＝番号10 を基準。スクリプトの `day_index`）
- 日の境目は**0時**（日本時間の日付そのもの）。
- 検算（スクリプト実行結果）：
  - 2000-01-01 → 年柱 己卯・月柱 丙子・日柱 **戊午**（外部の万年暦 wannianli.tianqi.com の「己卯年 丙子月 戊午日」と一致）
  - 1949-10-01 → 甲子
  - 2027-01-01 → 庚辰
  - 2027-12-31 → 甲申

### 2-4. 日干10タイプ
日柱の天干（`day_index % 10`）で10タイプに分けます（0＝甲 … 9＝癸）。

## ③ 解釈の表

### 3-1. 五行の相生・相剋・比和

- **相生（そうしょう）＝生み育てる関係**：木 → 火 → 土 → 金 → 水 → 木
  （木が燃えて火に、火が燃え尽きて土に、土の中から金属、金属の表面に水、水が木を育てる）
- **相剋（そうこく）＝抑える関係**：木 → 土 → 水 → 火 → 金 → 木
  （木の根が土を締め付け、土が水をせき止め、水が火を消し、火が金属を溶かし、金属の刃が木を切る）
- **比和（ひわ）＝同じ五行どうし**：力が重なり強まる関係。

ある五行Aから見た五行Bの関係は次の5種類です（フェーズ4の計算で使う名前）。

| 関係の名前 | 意味 | 例（Aが木） |
|---|---|---|
| 比和 | 同じ五行 | 木と木 |
| 生じられる | BがAを生む（助けてもらう） | 水 → 木 |
| 生じる | AがBを生む（自分の力を与える） | 木 → 火 |
| 剋す | AがBを抑える（自分が主導、力を使う） | 木 → 土 |
| 剋される | BがAを抑える（プレッシャー） | 金 → 木 |

### 3-2. 西洋の4エレメントとの対応（このサイト独自の対応ルール）

西洋占星術のエレメント（火・地・風・水）と五行は本来別の体系で、決まった対応はありません。このサイトでは、**フェーズ4で「月の干支（月柱）」と「本人の星座のエレメント」の関係スコアを出すため**に、次の対応を独自ルールとして決めます。

| 星座のエレメント | 星座 | 対応させる五行 |
|---|---|---|
| 火 | 牡羊座・獅子座・射手座 | 火 |
| 地 | 牡牛座・乙女座・山羊座 | 土 |
| 風 | 双子座・天秤座・水瓶座 | **木** |
| 水 | 蟹座・蠍座・魚座 | 水 |

**風を「木」にした理由**：
1. 易の八卦では「風」を表す巽（そん）が五行の**木**に当たります（九星気学でも四緑木星＝巽＝風）。東洋の体系の中で「風＝木」の対応がすでにあるため、根拠を説明しやすい。
2. 風のエレメントの性質（コミュニケーション・広がり・人とのつながり）は、四緑木星の象意（風・ご縁・取引・遠方）とよく重なります。
3. 「金」に当てる案（秋・天秤座の季節、乾＝天）も考えましたが、天秤座以外の双子座・水瓶座の季節と合わず、性質の説明も弱いため採りません。

注意：この対応では**「金」に当たるエレメントがありません**。月柱に金（庚・辛・申・酉）が出てくる月は、本人側の五行との関係（3-1の5種類）だけで判定します。

月柱には天干と地支の2つの五行があります（例：壬寅＝水と木）。フェーズ4では両方をそれぞれ本人の五行と比べて使います（重みづけはフェーズ4で計算ルールとして決め、`knowledge` に追記します）。

### 3-5. 2027年＝丁未（ひのと・ひつじ）の年

- 番号43。前回は1967年、その前は1907年（60年ごと）。立春 2027-02-04 10:46 〜 2028-02-04 16:31（スクリプトの節入り表より）。
- **丁**＝陰の火（灯火）、**未**＝陰の土（夏の終わり、南南西、13〜15時）。
- 天干と地支の関係は**火が土を生む（相生）**。上の火が下の土を温めて育てる、流れのよい組み合わせです。
- このサイトでの年運の読み方（全員共通）：
  - 前年2026年の丙午（陽の火×陽の火）は太陽が真上にあるような勢いの年。2027年は**火の温度が下がり、灯火のように身近な場所を照らす年**。
  - 外に向かって大きく広げるより、**暮らし・家族・身近な人間関係を温め、これまでの情熱を形（土＝実り・土台）にする年**。
  - 未は夏の終わり＝収穫前の準備期。「すぐ結果を求めず、実りの秋に向けて整える」姿勢が合います。
  - 注意点は、土の性質が強まる＝慎重になりすぎる、腰が重くなる、こだわりが強くなること。

### 3-7. 地支どうしの基本の関係（日の干支・月柱との関係で使う可能性があるもの）

| 名前 | 組み合わせ | 意味（このサイトでの使い方） |
|---|---|---|
| 支合（しごう）＝六合 | 子と丑、寅と亥、卯と戌、辰と酉、巳と申、午と未 | 引き合い、結びつく関係。協力・縁が生まれやすい（吉） |
| 三合（さんごう） | 申・子・辰（水）、亥・卯・未（木）、寅・午・戌（火）、巳・酉・丑（金） | 3つそろうと一つの五行の力が強まる仲間関係。2つでも「半分の三合」として良い関係（吉） |
| 冲（ちゅう）＝六冲 | 子と午、丑と未、寅と申、卯と酉、辰と戌、巳と亥 | 方位が正反対でぶつかる関係。変化・動き・衝突（注意） |

- 2027年の年支「未」との関係：支合は**午**、三合の仲間は**亥・卯**、冲は**丑**（九星気学の歳破＝北東＝丑の方位と同じ考え方）。
- 天干どうしにも「干合」（甲と己、乙と庚、丙と辛、丁と壬、戊と癸）がありますが、このサイトでは現時点で使う予定はありません（使う場合は追記）。
- 刑・害・破などの細かい関係は流派差が大きいので扱いません。

2. 日の境目を0時にしています。四柱推命には23時（子の刻の始まり）で日を切り替える流派もあります。誕生日ページは時刻を扱わないので影響はありません。
3. 十二支の陰陽は「順番による区別」で書いています。四柱推命では子・亥・巳・午の陰陽を中の要素（蔵干）で逆に扱う流派があります。
