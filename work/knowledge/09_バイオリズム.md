# 09 バイオリズム

計算スクリプト：`work/scripts/calc_maya_num_bio.py`（関数 `bio()` / `mark()`）
このファイルの値はすべてスクリプトの実行結果です。

## ① 定義

- バイオリズムは、人の調子が **生まれた日から一定の周期で上下する** と考える占い・読み物です。19世紀末〜20世紀初めにヴィルヘルム・フリースやヘルマン・スヴォボダらが唱えた考えがもとになり、1970年代ごろに一般に広まりました。
- 次の3本の波（正弦波）で表します。

| 線 | 周期 | 表すもの |
|---|---|---|
| 身体 | 23日 | 体力・体の動き・疲れにくさ |
| 感情 | 28日 | 気分・感受性・人づきあい |
| 知性 | 33日 | 考える力・判断力・集中力 |

- **科学的な根拠は認められていません。** これまでの検証で、この3つの周期が人の調子や事故などと関係するという結果は得られておらず、学術的には疑似科学とされています。このサイトでは **娯楽（読み物）として扱い**、ページにもその旨を一言書きます。体調や重要な判断の根拠にはしないよう案内します。

## ② 計算方法

### 式

- 経過日数 `n ＝ 対象日 − 出生日`（**出生日＝0日**。日数で数え、時刻は扱わない）
- 各線の値 `v ＝ sin(2π × n ÷ 周期)`（−1〜＋1）
- 出生日は3本とも0（スクリプト結果：1990-01-01生まれの1990-01-01 → 身体0.0・感情0.0・知性0.0）。そこから上がり始めます（n＝5 → 身体0.979・感情0.901・知性0.815）。
- 2/29の扱い：通常の暦日数で数えます（2/29も1日として数える。マヤ暦とは違う）。

### 5段階の判定（`mark`）

| 記号 | 条件 | 読み方 |
|---|---|---|
| ★ | v ≥ 0.8 | 絶好調 |
| ◎ | 0.4 ≤ v < 0.8 | 好調 |
| 〇 | −0.2 ≤ v < 0.4 | ふつう |
| △ | −0.6 ≤ v < −0.2 | やや低め（無理をしない） |
| ▽ | v < −0.6 | 低め（休む・整える） |

- 境界はちょうどの値を上の段に入れます（0.8は★、0.4は◎、−0.2は〇、−0.6は△）。スクリプトで確認済み。

### 総合の出し方（このサイトの案）

- **総合 ＝ 3本の平均**（`(身体＋感情＋知性) ÷ 3`）。総合にも同じ5段階の記号を使います。
- 参考（スクリプトで2027年の365日を計算）：1990-01-01生まれでは ★5日・◎53日・〇187日・△95日・▽25日。平均なので★はまれ（年に数日〜十数日）になります。

### 好調日の判定ルール（1つに決める）

- **好調日 ＝ 総合（3本の平均）が 0.6 以上の日。**
- 参考：2027年で 1990-01-01生まれ 29日、1975-06-15生まれ 23日、2001-11-30生まれ 27日（月に2日前後）。

### 要注意日の判定ルール（1つに決める）

- **要注意日 ＝ その日（経過日数 n から n+1 の間。n は含み n+1 は含まない）に、3本のうち1本以上が 0 を横切る日。**
  - 式：周期 p について `ceil(2n/p) < 2(n+1)/p` が成り立てば、その線がその日に0を横切る。
  - 0を横切るのは各線で周期の半分ごと（身体11.5日・感情14日・知性16.5日ごと）。出生日（n＝0）は3本とも0なので要注意日に当たります。
  - 例（スクリプト）：n＝11（身体）、14（感情）、16（知性）、23（身体）が要注意日。
- 参考：2027年で 1990-01-01生まれ 72日、1975-06-15生まれ 74日、2001-11-30生まれ 73日（月に6日前後）。
- 表示では、2本以上が同じ日に0を横切る日（年に5〜7日）だけを「特に注意」と強調してもよい（任意。採用する場合はこの基準で）。

### 使う場所（重要）

- バイオリズムは **生まれ年（正確には生年月日）が無いと計算できません**。同じ月日でも生まれ年が違えば値はまったく変わります。
- そのため **366ページの本文には書きません。** 生年月日を入れてもらう **「生まれ年パネル」専用** の内容とします。

## ⑤ 不確かな点

1. **判定のしきい値・総合・好調日・要注意日のルール** は、伝統的に決まった基準ではなく、このサイトで決めたもの（スクリプトのしきい値に合わせた）。
2. **要注意日の数え方：** 0を横切る「その日」をどう決めるか（横切る直前の日／直後の日／値がいちばん0に近い日）は流派やサイトで違う。このサイトは「n から n+1 の間に横切る日」に固定。
3. **出生日を0日とするか1日とするか：** サイトによって1日ずれる場合がある。このサイトはスクリプトどおり出生日＝0日。
4. **由来の人物・年代：** フリース、スヴォボダ、テルチャー（知性の周期）など複数の説明があり、細部は未確認。
5. 好調日・要注意日の日数は、例に挙げた3つの生年月日での実測。生年月日によって前後する。
