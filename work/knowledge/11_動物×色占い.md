# 11 動物×色占い（サイト独自・60タイプ）

> 状態：✅（2026-10-10 本人が `source/animal-color/計算方法.md` に現行ページの計算を書き写してくれたものを採用）

## ① 定義
- サイト独自の占い。12の動物×5つの色＝60タイプ。一般の「動物占い」とは別物で、**「動物占い」という名前は使わない**。
- 生年月日すべてで決まる → 366ページの本文には書かず、「生まれ年パネル」で結果を出して `/animal-color/` へ送る。

## ② 計算方法（現行 `/animal-color/` の `calculateAnimal` と同じ）
```
base   = (西暦年 + 月×12 + 日) mod 60     … 月は1〜12、日は1〜31をそのまま
動物   = ANIMALS[base mod 12]
色     = COLORS[floor(base ÷ 12) mod 5]
```
- 再現スクリプト：`work/scripts/calc_animal_color.py`（`animal_color(year, month, day)`）
- 検算：1990年1月1日 → base 23 → たぬき・ゴールド（本人の検算例と一致）。1930〜2020年で60タイプすべてが出ることを確認。
- 立春や節入りは関係しない（暦の切り替えなし。1月1日で年が変わる）。
