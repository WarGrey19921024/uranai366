# 14 数秘術ページ（/suhijutsu/）の規則（2026-10-18）

- 計算は `08_数秘術.md` と同じ（366日ページ・まるごと診断と数が食い違わないように）
  - ライフパス：生年月日8けたを全部足して1けたに。11・22・33は残す（全けた合計方式）
  - 誕生日の数：日だけを1けたに。11・22は残す
  - 2027年の数（パーソナルイヤー）：2+0+2+7＋誕生月と誕生日の各けた → 1〜9（マスターを残さない）。1月1日切り替え
  - ページ側の計算（JS）と Python（`build_suhi.py` の `py2027`）が、366日すべてで `base_366.json` の py2027 と一致することを確認済み
- 相性：このサイトの決め方。1〜9を3つのグループに分ける（動く数1・5・7／整える数2・4・8／響く数3・6・9）。11→2、22→4、33→6のグループで見る
  - 同じグループ◎（5）、動×響・整×響○（4）、動×整△（3）。「合わない」とは書かない
  - 1・5・7などの三つ組は、数秘術の解説でよく使われる「数の性質の近さ」で組んだ。特定の流派の相性表の写しではない
- 文章：`scripts/suhi_texts.py`。366日ページの数秘の説明（08の表）とは別に書き起こした
- 古い静的ページ /number-fortune/（好きな数字3つで読む「数字占い」）は、このページの「好きな数字で読む」にまとめて 301（ローカル・.htaccess）
