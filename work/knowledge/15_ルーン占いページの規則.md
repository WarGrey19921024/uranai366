# 15 ルーン占いページ（/rune/）の規則（2026-10-18）

- 使う文字：エルダー・フサルク24文字＋ブランク（ウィルド）＝25個。現代のルーン占いで最も広く使われる組み合わせ
- 並び順：3つのエット（フレイ・ハガル・ティール）の順。最後の2文字（ダガズ・オシラ）は本によって入れ替わるが、このサイトはダガズ→オシラ
- 逆位置を取らないルーン（形が上下対称、または逆位置を読まないとされるもの）：ゲーボ・ハガラズ・ナウシズ・イサ・ジェラ・エイワズ・ソウェイル・イングワズ・ダガズの9つ＋ブランク。逆位置を取れるルーンは、引いたとき3回に1回の割合で逆位置にする（このサイトの決め方）
- 引き方：1つ引き（答え）・3つ引き（過去・現在・未来）・5つのクロス（中央＝現在、左＝過去、右＝未来、上＝助言、下＝障害。旧静的ページの5つのクロスを引きつぐ）。同じ石は重ねて引かない
- 文章：`scripts/rune_texts.py`（このサイトの言葉。各ルーンの「もとの意味」は文字の名前の由来として広く知られているもの）
- 文字の表示：Google Fonts の Noto Sans Runic を読み込み、Windows は Segoe UI Historic でも出る
- URL：静的ページだった /rune/ をそのまま WordPress の固定ページに（静的のフォルダはローカルでバックアップしてから外す）
