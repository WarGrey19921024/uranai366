# 16 トランプ占いページ（/trump/）の規則（2026-10-18）

- カード：52枚＋ジョーカー。マーク＝何についての答えか（ハート＝気持ち・ダイヤ＝お金と現実・クラブ＝行動と成長・スペード＝試練と知恵）、数字＝段階（A始まり→10完成、J・Q・Kは人）。トランプ占いで広く使われる読み方
- 逆位置は使わない（トランプは上下の区別がないカードが多いため。FAQにも書く）
- 出し方：画面で引く（ジョーカーを含む53枚から重ならずに引く）／手もとのカードを選ぶ（旧静的ページの使い方を引きつぐ）
- 枚数：1枚（答え）・2枚（今の状況・これから）・3枚（過去・現在・未来）。2枚以上のときは同じマークが2枚以上あればそのマークを「全体の流れ」とする（このサイトの決め方）
- 文章：`scripts/trump_texts.py`（このサイトの言葉。旧静的ページの1行の意味は使っていない）
- マークの記号には異体字セレクタ（U+FE0E）をつけ、スマホで絵文字にならないようにする
- URL：静的の /trump/ をそのまま WordPress に。/trump/one/・/two/・/three/ は /trump/ へ301（ローカル）
- Diver は JS の中の [sp] [pc] などをショートコードとして消すので、そういう書き方をしない（build でassert）
