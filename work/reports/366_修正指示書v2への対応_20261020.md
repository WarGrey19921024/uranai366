## A・B 検索語（表示名と検索語を分けた）
- しくみ：表示名（読者に見せる品名）はこれまでどおり。リンクの検索語は別に持つ。
  1. 日ごとの検索語 `data/ad_leads/MMDD.json` の `queries`（{表示名: 検索語}）。366日分を担当6人で作った。
  2. それが無い品名は、`norm_q()` が自動で「名詞中心・助詞なし・3語まで」にする（「の」で区切る、「小さな」「お気に入りの」などの飾りを外す、4語以上は「ギフト」「セット」から外す。「湯のみ」「きのこ」などは区切らない）。
  3. 楽天では商品ページに飛ぶのに Yahoo! では検索になるとき、`other_q()` が実際の商品名に入っている語だけを残す（例：ヘリオドール ブレスレット → 商品は粒なので「ヘリオドール」）。

- B（本文の検索のコツとリンクを一致させる）：検索語を作るときに、説明文に「〜で探す」と書いてあればその語を使った。説明文の方を直した日もある（例：0502、0612）。
- 点検：`scripts/check_ad_leads2.py`（検索語は名詞3語まで・「の」なし、プレゼントの説明の長さ、マグの可否）→ 366日すべて OK。

## C 商品画像が出ない
- 原因：テーマ（Diver）の遅延読み込みが、class のついた `<img>` の src を空にして data-src に移す。ページの取得結果だけを見ると src が空に見え、実機でも読み込みの処理が動かないと出ない。
- 対応：画像を `class=""`（空）にして、見た目は `data-fh` で当てる。Diver は空の class の画像には手を出さない（10/20 に試験ページで確認）。画像のキャッシュは不要だった。
