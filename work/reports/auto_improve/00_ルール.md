# 20分ごとの自動改善 ルール（2026-10-29 本人の依頼で開始）

本人の依頼：「20分ごとに改善。自分で改善点を調べて更新する。壊れないように事前か事後に確認する」。
1回（1サイクル）で直すのは **1か所（1ページ、または同じ直し方の小さなまとまり）だけ**。

## 1サイクルの流れ
1. **調べる**：下の「候補」から、または Search Console・本番の点検（`scripts/live_check.js`）で見つけたものから1つ選ぶ。`log.md` を読み、同じことを繰り返さない
2. **事前の控え**：変える前の本文・題名・説明文を `reports/auto_improve/backup/<日時>_<ID>.json` に保存（サイトに公開済みの内容なのでリポジトリに置いてよい）
3. **直す**：WordPress の REST（Claude in Chrome、ログイン済みのタブ）。本文は `<!-- wp:html -->` で包む。Claude が作ったページの元ファイルがあれば、元ファイル（build_*.py など）も直して作り直す
4. **事後の確認**：`FHCHK.pages([そのURL])` で 200・h1が1つ・説明文あり・禁止語なし → 実際に開いて `FHCHK.view()` で文字と背景の見え方（コントラスト）と横はみ出し（パソコン幅・スマホ幅）→ リンクを足したら `FHCHK.links()`
5. **だめなら戻す**：控えの内容で元に戻し、log に「戻した」と書く
6. **記録**：`log.md` に1行（日時・何を・なぜ・確認結果）。コミットして push。数回に1回は `00_進捗.md` にもまとめる

## やってよいこと（本人OKの範囲）
- Claude が作ったページ（366日・2027年の運勢・MBTI・吉日カレンダー・各占いの新ページ）の文章・見た目・内部リンクの改善
- 説明文（Diver の欄）・題名の改善（検索で表示が多いのにクリックが少ないページなど）
- リンク切れ・転送ずみURLへのリンクを正しいURLに直す
- 文字と背景が見えにくい箇所の修正
- 構造化データ・アイキャッチなど、見た目を変えない改善

## やらないこと（本人に聞く）
- 削除、URL（スラッグ）の変更、転送（.htaccess）、メニュー・テーマ・プラグイン・サイト全体の設定
- 2026年版の誕生日ページ（/2026-MMDD/）への変更（1/1 まで今のまま）
- 広告の位置・数を大きく変えること、新しいアフィリエイトの追加
- パスワード・ログイン・CAPTCHA・お金にかかわる操作
- 占いの値を記憶で書くこと（必ず計算 or 出典）。「動物占い」「六星占術」を使うこと
- 本人の手書き記事（Claude が作っていないページ）の本文を大きく書きかえること（誤字・リンク切れ程度は可）

## 止まるとき
- ログインが切れた・パソコン（Chrome）につながらない → その回は調べるだけ（Search Console や手元のファイル）にして、`log.md` と本人へのメッセージに書く
- 確認で壊れていたのに戻せない → 自動改善を止めて本人に知らせる
- 本人が「止めて」と言ったら止める
