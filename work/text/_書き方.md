# 文章の書き方（フェーズ6・7 共通）

この決まりは `docs/01_作業指示書.md` フェーズ5-2・5-3、`docs/04_本人の決定.md`（確認2）をまとめたもの。書く人（担当）は必ずこのファイルと、担当する日の素材（`work/data/materials_366.json`）だけを根拠に書く。

## 0. いちばん大事なこと
- **別の日で同じようなことを書かない。** 星座全体に当てはまる一般論は **1セクション1文まで**。残りは必ずその日の材料（七十二候・デーカン・誕生日の数・誕生花と花言葉・誕生日石・誕生色・記念日・相性の日付・スコアの山と谷の月・2027年の誕生日当日）で書く。
- 同じ星座の他の日と、**書き出し・文の型・語尾・たとえ**をそろえない。毎ページ、別の切り口で入る。
- 占いの値（天体・節気・干支・宿・九星・スコア・月の名前）は素材表の値だけを使う。**記憶や推測で書かない。** 素材表に無いことは書かない。
- 現行サイトの文章はコピーしない（見ない）。

## 1. 文体
- です・ます調。「！」は1ページ3回まで。
- 占いの断定はしない（「〜しやすい」「〜の暗示」「〜と良さそうです」）。健康・お金で不安をあおらない（病名・損失額などを書かない）。
- 専門用語は避けるか一言で言い換える。**本文に度数の数字（例：10度、120度）を出さない**（確認2）。根拠はページ下部の「この占いについて」で1回だけ説明する（テンプレート側で入れる）。
- 強調：太字 `**…**` とマーカー `==…==` を **各セクション1〜2か所**（多すぎない）。

## 2. 書くもの（JSONの形）
1日分は次の形。`work/text/<星座英名>.json` に `{"MMDD": {…}, …}` で保存する。

```json
{
  "fixed": {
    "personality": ["段落1", "段落2", "段落3"],          // 性格。計400〜550字。星座＋デーカン＋誕生日の数＋七十二候のイメージ＋花言葉
    "strengths": ["長所1", "長所2", "長所3"],           // 付箋。各15〜30字
    "cautions": ["注意点1", "注意点2"],                 // 付箋。各15〜30字
    "soul_message": "魂のメッセージ 120〜180字",          // 花言葉 or 七十二候＋誕生日の数
    "koyomi": "暦と星の解説 250〜350字",                 // 節気・七十二候・デーカン・誕生日の数を、その日の人に引きつけて
    "items": "誕生花・誕生石・誕生日石・誕生色の解説 150〜250字",
    "events_note": "記念日・できごとの一言 60〜100字",     // 素材の記念日（確認済みのもの）から1つ以上に触れる。無い日は七十二候の季節の話題
    "compat_good": [{"mmdd": "0501", "text": "…"}, …5件], // 各40〜70字。2人が一緒にいる場面（仕事・恋愛・友人・家族など）が浮かぶ言葉で
    "compat_bad":  [{"mmdd": "0331", "text": "…"}, …3件], // 各40〜70字。「気をつけたい誕生日」。責めずに、うまくいくコツで締める
    "famous_note": "有名人欄の一言 50〜90字",             // 素材の有名人から1〜2人の名前に触れ、その日の性格の材料と結びつける（職業・肩書きは素材どおり）
    "present": [{"item": "…", "why": "…"}, …4件]          // 誕生日プレゼント。各 why 30〜60字。お守りリストと同じ商品にしない
  },
  "y2027": {
    "fate": "その年の運命 280〜350字",                    // パーソナルイヤー＋主なアスペクト（素材の astro_hits を言葉で）＋山の月
    "guidance": "天からの導き 110〜160字",
    "fields": {"仕事": "200〜250字", "恋愛": "200〜250字", "金運": "200〜250字", "健康": "200〜250字", "人間関係": "200〜250字"},
                                                         // 各分野の山の月（field_peak_use）と谷の月（field_low_use）を必ず名前で入れる
    "growth": "成長 90〜130字", "decline": "衰え（気をつけたいこと）90〜130字",   // スコアの谷の月＋誕生日の数
    "eto": "丁未の年をこの日の人がどう過ごすか 100〜140字",
    "kyusei": "九紫火星中宮の年をこの日の人がどう過ごすか 90〜130字",
    "stars": "2027年の主な星の動きとこの日の人 150〜200字", // 素材の astro_hits と 2027年の天体（knowledge/02）から
    "seasons": ["1〜3月 60〜90字", "4〜6月", "7〜9月", "10〜12月"],
    "months": ["1月の一言 70〜100字（◎と△の月は120字まで）", …12件],               // その月の◎○△（scores.marks）とパーソナルマンスの意味・星の動きに合わせる
    "actions": [{"title": "…", "text": "40〜80字"}, …5件],  // 山の月・谷の月・誕生花・誕生石・記念日のどれかを使う
    "amulet": {
      "colors": [{"name": "…", "why": "…"}, …3件],          // 1つはデーカンの支配星の色、1つは誕生色にちなむ
      "items": [{"name": "…", "why": "…"}, …6件],
      "number": {"value": 4, "why": "…"},                    // パーソナルイヤー or 誕生日の数から

    },
    "bday": "2027年の誕生日当日の運勢 90〜130字",            // 曜日・日の干支・パーソナルデー

```

## 3. セクションごとの「必ず使う材料」（最低2つ）
| セクション | 材料 |
|---|---|
| personality | 星座＋デーカン（decan_meaning）＋誕生日の数＋七十二候のイメージ（kou_meaning）＋花言葉 |
| soul_message | 花言葉 or 七十二候＋誕生日の数 |
| fate | パーソナルイヤー（py2027_meaning）＋astro_hits の主な星＋山の月（peak_months） |
| fields | 各分野の field_peak・field_low の月（**月の名前はページごとに違う**） |
| growth / decline | low_months（谷の月）＋誕生日の数 |
| seasons / months | scores（marks・total）＋パーソナルマンス（pm2027）の意味＋星の動き |
| actions | 山の月・谷の月・誕生花・誕生石・記念日のどれか |
| amulet | デーカンの支配星の色・誕生石・パーソナルイヤー |
| bday | 曜日・日の干支（kanshi_meaning）・パーソナルデー（pd_meaning） |
| to_you | 七十二候 or 記念日 or 花言葉 |

## 4. 月の名前のルール
- 「山の月」「いちばん良い月」と書くのは `peak_months` の月、「慎重な月」「谷の月」は `low_months` の月だけ。分野別は **`field_peak_use`・`field_low_use`**（1ページで同じ月を3分野以上が山・谷にしないよう、点差の小さい分野は2番目の月 `field_peak2`・`field_low2` に回してある。スコア自体はそのまま）。分野別で「いちばん」と書けるのは `field_peak_use` が `field_peak` と同じときだけ。2番目の月のときは「良い月」「追い風の月」などと書く。**スコアと食い違う月を書かない**（検査で機械的に照合する）。
- 12か月の一言（months）は `scores.marks` の◎○△と矛盾しない調子で書く（◎の月に「控えめに」と書かない）。
- **確認3**：12か月のうち「月の数（パーソナルマンス）」に触れるのは **4か月まで**。同じ星の言い回し（「緊張の位置」「調和の位置」など）は **同じページで3回まで**。残りの月は、その月の季節の行事・旬・七十二候・記念日・誕生花・誕生日石など、その日の材料で書き分ける。12か月の書き出しを単調にしない。

## 5. 相性の一言（確認2の決定）
- 度数の数字を出さない。「太陽の角度が〜」のような説明はしない。
- 2人が一緒にいる場面（仕事・恋愛・友人・家族・旅・趣味など）が浮かぶ自然な言葉で。**文の型と語尾を毎回変える**。同じ締め（「〜と噛み合います」など）を繰り返さない。
- 素材の compat_good / compat_bad の `text`（根拠の説明）を読んで、根拠（調和・協力・同じ星座の仲間／摩擦・向かい合わせ、誕生日の数のグループ）に沿った中身にする。相手の日付の星座名は出してよい。

## 5-2. 誕生日石（確認3）
- 誕生日石は **月の誕生石とは別の石**（素材表の birthday_stone）。本文で「誕生石＝誕生日石」のように同じ石として書かない。お守りリストの守護石（amulet.stone）は、月の誕生石か誕生日石のどちらかを選び、2つを混同しない。

## 6. 禁止
- 六星占術・「動物占い」という言葉、現行サイトの文章、記憶による天体の日付、未確認の記念日（素材表に無いもの）。
- 「〜でしょう！」の多用、同じ書き出し（「〇月〇日生まれのあなたは」で毎ページ始めない）。
